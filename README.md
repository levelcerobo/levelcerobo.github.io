# levelcerobo.github.io

Página de guías gratis de Level 0 (la del QR del sticker impreso). Sirve dos PDF, con estos nombres fijos
porque los QR impresos apuntan a ellos:

- `guia-principiante.pdf` ← `Z:\Level0\dev\rubik-guia-principiante\Cubo-Rubik-Metodo-Principiante.pdf`
- `guia-f2l.pdf` ← `Z:\Level0\dev\rubik-guia-f2l\Cubo-Rubik-F2L-41-Casos.pdf`

Portadas: `img/portada-*.jpg` = página 1 del PDF a 910 px de ancho. Después de reconstruir una guía, copia su PDF
con ese nombre, regenera la portada, revisa páginas y tamaño en la tarjeta de `index.html`, y haz push.

OLL y PLL no se publican aquí (son para la tienda). La redirección a levelcero.com está guardada en
`Z:\Level0\levelceroweb\github-redirect\` para cuando haga falta.
